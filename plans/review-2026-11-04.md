# Pre-production review (2026-11-04, Windows, `main`)

Five area audits (webcam, voice, history and storage, sessions and activity, UI), each a full
read of its files against what the landing page and the app's own copy promise, plus a pass
over the build and release files. About ninety findings. What was fixed is in the commit of
this date; what was not is listed at the end, with why.

## Release blockers that are not code

1. **No GitHub Releases exist.** The app's voice engine download reads
   `releases/download/voice-runtime/voice-runtime-manifest.json` (404 today) and the Mac
   installer reads "latest". Until the `voice-runtime` pre-release (both zips and the manifest,
   `plans/distribution.md`) and a `v0.1.0` app release are uploaded, the engine download fails
   for every user and so does recording a voice, which is gated on it. The failure now reads as
   a plain sentence instead of raw HTTP text.
2. **Windows distribution is undecided** (`plans/distribution.md`, "Windows"). The frozen
   Windows webcam worker now exists on this machine (`build/webcam`, 233 MB, both self-tests
   pass) so a Windows bundle would ship with the webcam; what it is signed with and where it is
   downloaded from is not decided.
3. **Nobody has listened to the 104 bundled clips.** They are transcription-checked only.

## Fixed in this review

Promises that were not kept:

- Windows credited the front window as focused while the display was off without a lock
  (laptops after 10 min, desktops all night). A console display-state listener now returns the
  same "nothing recorded" disposition the lock screen gets; lost time, counted as Away. The Mac
  had this since 2026-10-31.
- History storage trouble was tracked by the backend and never shown. A banner with Dismiss
  now says when the database was reset, when history is off for this run, or when a save
  failed. The database also syncs fully on every commit (WAL kept), so a power cut no longer
  loses whole sessions.
- The Session done card could show the previous session's numbers after a failed save; it
  shows numbers only for the session that just ended.
- The session timer could be minimized from its own title bar and then never show a card; it
  is no longer minimizable, has no taskbar button, unminimizes when a card is due, and on
  Windows never takes keyboard focus from the browser. It also hears a reminder or Pomodoro
  moment the moment it is pushed, instead of on a throttled timer.
- Marking the window in front as a distraction, or saving a rule mid-session, played the
  reminder within a second; a newly matched place now starts its clock from now.
- A camera that failed to start during a session was silent; the error now reaches the
  session as a toast, the webcam page's picture is dropped when the worker errors, a failed
  switch says why, a GPU failure falls back to CPU on the next tick instead of 30 s later (and
  on the webcam page too), raw ONNX banners no longer reach the page, and a camera or GPU
  change in Settings reaches a running session.
- Voice engine and model downloads resume where they stopped, with connect and read timeouts
  instead of a 15-minute cap that a slow link could never meet. Errors are sentences.
- Generation has a Cancel for a stuck line; leaving the Voice page says that generation stops
  after the current line. Custom lines past 100 were silently dropped; the limit is 1000 and
  the 1001st is refused with a sentence.
- On Windows, generated and saved paths carried the `\\?\` prefix, so a regenerated line's
  play button could serve the cached old audio. Paths are plain everywhere.
- Recordings under 5 s are refused with what to do; the silent-microphone message names the
  settings path for the OS it runs on; the record dialog has a passage to read, as the help
  said it did.
- Trends door said "First week · nothing before it" for the oldest week of its eight-week
  window when older weeks existed. The day card's streak now matches the calendar's.
  "Delete all history" vacuums the file so the space is really freed. Streaks past 120 days
  no longer read as 120.
- Allow once chips compared app rules case-sensitively against lowercase exceptions.
  "Rounds" counted breaks plus one; it counts rounds started. The Break over card says the real
  wait. Mute 5 min is on the main session page, so the timer window is not the only way.
- Settings fit 920x760 again (the Delete all history row was below the fold); the main window
  has a minimum size of 920x760.
- Copy: "phone or watch" in the report, timeline and session labels; vocabulary violations
  (clips, worker, model, sample, tone, cloning) across the Voice page, backend errors, the
  busy and delete dialogs and Info.plist; "Tap" is "Click"; the landing page's "What it
  reads" names presence, window titles and the lock screen, and personality is per voice.
- Dead code: the webcam page's never-set strictness and reaction settings, five unused voice
  helpers, the old 20-line default set in the backend, three dead seeded settings.

## Found and left, with why

- **A worn smartwatch may be a permanent false positive.** The detector has only the COCO
  "cell phone" class at a 0.15 score and an 8 px minimum box; a watch face that scores every
  frame cannot clear hysteresis. Needs a desk test with a watch, a remote and a mug before the
  word "watch" is leaned on; a minimum box size relative to the frame is the likely fix.
- **Chrome and Edge installed web apps (PWAs) count as work on Windows**: the window is the
  browser but has no address bar, so the address read fails and the title rarely names the
  site. Needs a command-line or title heuristic; on the Mac it lands as an app instead.
- **Clicking the address bar for 1.5 s, or Alt-Tab and back, resets a distraction's clock**
  on Windows. A "same place within N seconds resumes" rule in `focus.rs` would close it.
- **Away is only from the camera, sleep and lock** by the 2026-10-30 decision; no change.
- **Pomodoro and duration choices do not persist across restarts**; nothing promises it.
- **A session crossing midnight is credited to its start day** everywhere, consistently.
- **No focus trap in dialogs**; Escape works everywhere.
- **Every poll tick carries the whole history list** (one second, both windows); fine today,
  linear in sessions.
- **The webcam page's picture is not restarted after the main window is hidden and shown**
  from the tray; leaving and re-entering the page fixes it.
- **Starter voices with a personality that has no Back to work line** are now unselectable
  like recorded ones; the footer already explained it.
- Browser list gaps on Windows (Zen, Waterfox, LibreWolf, Floorp) count as apps.
- The 4 GB RAM gate on a 16 GB Mac with apps open (`known-issues.md`).
