# Release 1.0: the steps, in order

Two GitHub Releases. The app reads the voice engine manifest from the `voice-runtime` tag and
the Mac installer reads "latest", so the pre-release must be marked pre-release and the app
release must be the latest. Nothing in the app changes for a new engine; nothing in the engine
changes for a new app.

## Mac assets (to build on the Mac, with the "Supervisor Dev" certificate present)

```
sh scripts/release-mac.sh                      # build/release/Supervisor-macos-aarch64.zip + .sha256
.venv-voice-runtime-macos/bin/python scripts/build_voice_runtime.py   # build/voice-runtime/...-macos-arm64.zip
```

Then copy the Mac `supervisor-voice-runtime-macos-arm64.zip` and its `.asset.json` next to the
Windows ones on whichever machine uploads.

## Upload (needs `gh auth login` once)

1. Engine pre-release, both zips first, so their asset URLs exist:

```
gh release create voice-runtime --prerelease --title "Voice engine" --notes "The voice engine Supervisor downloads on first use. Not an app release." \
  build/voice-runtime/supervisor-voice-runtime-windows-x64.zip \
  build/voice-runtime/supervisor-voice-runtime-macos-arm64.zip
```

2. Put each zip's release URL into its `.asset.json` (`url`), in the form
   `https://github.com/pr4nav3/Supervisor/releases/download/voice-runtime/<zip name>`,
   then build the manifest from both and upload it:

```
python scripts/build_voice_runtime_manifest.py --version 2026-11-05 \
  --output build/voice-runtime/voice-runtime-manifest.json build/voice-runtime/*.asset.json
gh release upload voice-runtime build/voice-runtime/voice-runtime-manifest.json
```

3. App release, marked latest:

```
gh release create v1.0 --latest --title "Supervisor 1.0" --notes-file plans/release-notes-1.0.0.md \
  build/release/Supervisor-macos-aarch64.zip build/release/Supervisor-macos-aarch64.zip.sha256 \
  src-tauri/target/release/bundle/nsis/Supervisor_v1.0_x64-setup.exe
```

4. Check from a clean machine: the Mac one-liner installs and opens; on Windows the setup runs
   and the Voice engine tile downloads and generates a line; `docs/site.js` `RELEASES` gets the
   two download URLs and the "Not out yet" block goes.

## Windows installer name (2026-11-05)

`scripts/install-win.ps1` no longer asks the GitHub API (60 calls an hour per address, which a
shared office or school network runs out of); like `install-mac.sh` it fetches fixed names from
`releases/latest/download/`. So the Windows installer goes on `v1.0` under one name only,
`Supervisor-windows-x64-setup.exe`, with `Supervisor-windows-x64-setup.exe.sha256` beside it.
When the rebuilt installer is uploaded, delete the old `Supervisor_v1.0_x64-setup.exe` asset
(`gh release delete-asset v1.0 Supervisor_v1.0_x64-setup.exe`). Until then the one-liner fails
with a red "could not download" message.

## Rebuild list (after the 2026-11-05 fixes)

The Windows half runs on this machine, the Mac half on the Mac, with the same "Supervisor Dev"
certificate. In order:

1. **Voice engine zips, both targets.** The worker script changed (it reads and writes UTF-8,
   so accented paths and line text work on Windows). On each OS run
   `scripts/build_voice_runtime.py`, bring both `.asset.json` files together, run
   `scripts/build_voice_runtime_manifest.py` (no `--partial`), then upload both zips and the
   manifest to the `voice-runtime` pre-release with `gh release upload voice-runtime ... --clobber`.
2. **Webcam worker**, on each OS: `scripts/build_webcam_runtime.py` (its face-model loader
   changed). The app build below bundles it, so do this first.
3. **The app**, on each OS.
   - Windows: `npx tauri build --bundles nsis --config src-tauri/tauri.bundle.conf.json`, then
     copy the setup exe from `src-tauri/target/release/bundle/nsis/` to
     `Supervisor-windows-x64-setup.exe`, write its hash with
     `"$((Get-FileHash Supervisor-windows-x64-setup.exe).Hash.ToLower())  Supervisor-windows-x64-setup.exe" | Set-Content -Encoding ascii Supervisor-windows-x64-setup.exe.sha256`,
     and `gh release upload v1.0 Supervisor-windows-x64-setup.exe Supervisor-windows-x64-setup.exe.sha256 --clobber`;
     delete the old `Supervisor_v1.0_x64-setup.exe` asset.
   - Mac: `sh scripts/release-mac.sh`, then
     `gh release upload v1.0 build/release/Supervisor-macos-aarch64.zip build/release/Supervisor-macos-aarch64.zip.sha256 --clobber`.
4. **Release notes:** `gh release edit v1.0 --notes-file plans/release-notes-1.0.0.md`.
