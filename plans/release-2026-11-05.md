# Release 1.0: the steps, in order

Two GitHub Releases. The app reads the voice engine manifest from the `voice-runtime` tag and
the Mac installer reads "latest", so the pre-release must be marked pre-release and the app
release must be the latest. Nothing in the app changes for a new engine; nothing in the engine
changes for a new app.

run (More info, Run anyway). The engine zip was installed through the app's own install code
(`manual_install_real_runtime_zip`) and the installed worker made a line from the command line.

## Mac assets (to build on the Mac, with the "Supervisor Dev" certificate present)

```
sh scripts/release-mac.sh                      # build/release/Supervisor-macos-aarch64.zip + .sha256
.venv-voice-runtime-macos/bin/python scripts/build_voice_runtime.py   # build/voice-runtime/...-macos-arm64.zip
```

Then copy the Mac `supervisor-voice-runtime-macos-arm64.zip` and its `.asset.json` next to the
Windows ones on whichever machine uploads.

## Upload (needs `gh auth login` once)

1. Engine pre-release, both zips first, so their asset URLs exist:

```
gh release create voice-runtime --prerelease --title "Voice engine" --notes "The voice engine Supervisor downloads on first use. Not an app release." \
  build/voice-runtime/supervisor-voice-runtime-windows-x64.zip \
  build/voice-runtime/supervisor-voice-runtime-macos-arm64.zip
```

2. Put each zip's release URL into its `.asset.json` (`url`), in the form
   `https://github.com/pr4nav3/stealth-startup/releases/download/voice-runtime/<zip name>`,
   then build the manifest from both and upload it:

```
python scripts/build_voice_runtime_manifest.py --version 2026-11-05 \
  --output build/voice-runtime/voice-runtime-manifest.json build/voice-runtime/*.asset.json
gh release upload voice-runtime build/voice-runtime/voice-runtime-manifest.json
```

3. App release, marked latest:

```
gh release create v1.0 --latest --title "Supervisor 1.0" --notes-file plans/release-notes-1.0.0.md \
  build/release/Supervisor-macos-aarch64.zip build/release/Supervisor-macos-aarch64.zip.sha256 \
  src-tauri/target/release/bundle/nsis/Supervisor_v1.0_x64-setup.exe
```

4. Check from a clean machine: the Mac one-liner installs and opens; on Windows the setup runs
   and the Voice engine tile downloads and generates a line; `docs/site.js` `RELEASES` gets the
   two download URLs and the "Not out yet" block goes.
